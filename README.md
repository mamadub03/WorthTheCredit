# WorthTheCredit

AI-powered, crowdsourced RIT course discovery and recommendation platform.

## Frontend

The web app is a React, Vite, and TypeScript project in `frontend/`.

```bash
cd frontend
npm install
npm run dev
```

Open the URL Vite prints (http://localhost:5173 by default).

AI assistance is logged in [`docs/ai-contributions.md`](docs/ai-contributions.md) so it can be cited.
